SimpleHypervisor

A type-2 hypervisor built directly on the Linux KVM API, with no QEMU involved. It boots an unmodified Linux kernel to an interactive BusyBox shell in about one second.

  • Implements the x86 Linux boot protocol by hand: loads the bzImage and initramfs, fills in boot_params, the e820 memory map and the kernel command line
  • Builds a GDT and puts the vCPU straight into 32-bit protected mode
  • Emulates a 16550 UART with interrupt-driven I/O on IRQ 4, with a separate input thread so the guest console is interactive

  • Linux boot protocol

Bare-metal Preemptive Scheduler

The core of an RTOS for the ARM Cortex-M4, running on an STM32 NUCLEO-F401RE board. It uses no HAL, no vendor startup code and no libraries.

  • Hand-written linker script, interrupt vector table and reset handler that sets up .data and .bss
  • SysTick triggers PendSV, which performs a round-robin context switch in assembly
  • Tasks run on the process stack (PSP) using EXC_RETURN, and each new task starts from a hand-built fake stack frame
  • Debugged on the board with GDB and st-util

void fetch_chip8(Chip8* chip8) {
    // opcodes are 2 bytes, big-endian
    chip8->opcode  = chip8->memory[chip8->pc] << 8;
    chip8->opcode |= chip8->memory[chip8->pc + 1];
    chip8->pc += 2;
}

CHIP-8 Emulator in progress

An interpreter for the CHIP-8 virtual machine. It models the memory map, 16 registers, the call stack and the timers, and runs a fetch–decode–execute loop.

  • Loads ROMs into the non-reserved part of memory starting at 0x200
  • Decodes opcodes by nibble (X, Y, N, NN, NNN) and already handles jumps, calls, conditional skips and register operations
  • Next steps: drawing sprites, keypad input and the display frontend
